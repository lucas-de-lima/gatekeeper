# Gatekeeper — Managed Target

This workspace is a `managed_target` for a new project. It starts in
`target_discovery`.

Read in this order:

1. `.harness/project-manifest.yaml`
2. `.harness/TARGET_CONTEXT.yaml`
3. `.harness/MEMORY.md`
4. `.harness/LOG.md`
5. `.harness/blueprint/`
6. `docs/` brainstorm documents

No feature or implementation is authorized until the operator provides an
explicit product request. Preserve facts, hypotheses, unknowns and evidence
separately.
